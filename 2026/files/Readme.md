# files - 完全マウス対応 TUI ファイルマネージャ

Node.js 標準 API のみ（外部依存ゼロ）で動作する、左右2ペイン構成の **完全マウス操作対応** TUI ファイルマネージャ。

## 特徴
- **外部依存ゼロ**: Node.js 標準ライブラリのみで動作。
- **すべての操作がマウスで完結**:
  - **選択 & 移動**: ファイル/フォルダのクリックで選択、ダブルクリックでフォルダ遷移 / ファイルプレビュー。
  - **右クリックメニュー**: アイテム上で右クリックするとコンテキストメニュー（開く/プレビュー、リネーム、コピー、移動、新規フォルダ、削除、選択切替）を表示して直接操作。
  - **ヘッダボタン**: 各ペインヘッダに `[⬆️上へ]` (親ディレクトリへ移動)、`[⟳更新]` (再読込)、`[全選択]` を配置。
  - **ソート操作**: ヘッダの `名前` / `サイズ` / `更新日時` をクリックするだけで昇順・降順切り替え。
  - **D&D 転送**: ペイン間でファイルをマウスドラッグ＆ドロップしてコピーまたは移動。
  - **ダイアログ操作**: リネーム・新規フォルダ・削除確認・プレビュー画面など、すべてのダイアログに `[決定]` `[クリア]` `[キャンセル]` `[スクロール]` ボタンを装備。
  - **下部ツールバー**: `[F1:ヘルプ]` `[F2:リネーム]` `[F3:表示]` `[F5:コピー]` `[F6:移動]` `[F7:新規フォルダ]` `[F8:削除]` `[Tab:切替]` `[F10:終了]` を直接マウスクリック可能。

## 実行方法

```shell
# 直接起動
node files.mjs

# または mise
mise run tui
```
