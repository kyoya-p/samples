# files - 完全マウス対応 TUI ファイルマネージャ

`files` は、PowerShell や Windows Terminal、Orca ターミナル等の VT シーケンス対応端末で軽快に動作する、**依存パッケージゼロ（Node.js 標準 API のみ）** の左右2ペイン構成 TUI ファイルマネージャです。

すべての操作がマウス（クリック、ホバー、ドラッグ＆ドロップ、ホイールスクロール、右クリックメニュー）で完結するように設計されています。

## 実行・テスト手順

### 1. アプリ起動

```powershell
# 直接起動
node files.mjs

# mise 経由で起動
mise run tui
```

### 2. テスト実行

```powershell
# 基本ファイル操作テスト
node test.mjs
# または
mise run test

# マウス操作・ホバー・パンくず総合検証
node verify_tui.mjs
```

## 主な機能とマウス操作仕様

### 1. パンくずリスト (Breadcrumbs)
- パスを `[works]` `[samples]` `[2026]` `[files]` の個別ボタンタグとしてレンダリング。
- マウスホバーで黄色反転、クリックで該当階層へ直接ジャンプ。

### 2. マウスホバー可視化 (VT `\x1b[?1003h`)
- マウスカーソルを重ねた対象（ボタン、パンくず、ソート項目、ファイル行）が **`BG_YELLOW + FG_BLACK + BOLD`** でリアルタイムに強調表示され、クリック可能な対象を明示。
- ステータスバーに現在座標 `[X:.., Y:.. | 対象: ..]` をリアルタイム表示。

### 3. ヘッダ・ツールバー操作
- `[切替]`: ドライブ（`C:\`, `D:\`等）やホーム、親階層を選択するポップアップメニューを表示。
- `[上へ]`: 親ディレクトリへ1階層移動。
- `[更新]`: ディレクトリ再読み込み。
- `[全]`: ペイン内アイテムの一括選択 / 解除。
- `名前↑` / `サイズ` / `更新日時`: クリックで昇順・降順ソート切り替え。
- 下部ツールバー (`[F1:ヘルプ]`, `[F2:リネーム]`, `[F3:表示]`, `[F4:切替]`, `[F5:コピー]`, `[F6:移動]`, `[F7:新規]`, `[F8:削除]`, `[Tab:切替]`, `[F10:終了]`): 直接マウスクリック可能。

### 4. ファイル一覧操作
- **左クリック**: アイテム選択 / カーソル移動。
- **ダブルクリック**: フォルダ展開 / ファイルのテキストプレビュー表示。
- **右クリック**: コンテキストメニュー（開く、リネーム、コピー、移動、新規作成、削除、選択切替）表示。
- **ドラッグ＆ドロップ**: 左右ペイン間でのファイル掴み＆離しによるコピー/移動。
- **ホイールスクロール**: 上下ホイールでリストおよびプレビュー画面のスクロール。

### 5. ダイアログ操作
- リネーム・新規作成・削除確認・プレビュー画面に `[決定]` `[クリア]` `[キャンセル]` `[スクロール]` `[閉じる]` ボタンを完備し、マウスのみで完結。

## 開発・保守ルール

1. **文字幅・座標計算の厳密性**:
   - 絵文字・全角文字は幅2、半角文字は幅1、ゼロ幅セレクタ（VS16等）は幅0として厳密に計算すること。
   - レンダリング時の `x1, x2` 登録位置と実際の端末表示桁位置が1:1で一致していることを常に維持すること。
2. **外部依存ゼロの維持**:
   - `node:fs`, `node:path`, `node:readline` 等の標準ライブラリのみで完結させ、`package.json` の外部依存を追加しないこと。
