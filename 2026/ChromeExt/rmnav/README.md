# Redmine Graph Navigator (rmnav) — Chrome 拡張機能 (MV3)

現在開いている Redmine ページ（チケット詳細・チケット一覧・ガントチャート・ロードマップ等）から、チケット同士のリレーション（親子・ブロック・先行後続・関連・重複・コピー・本文/コメント記載リンク）を Vis.js でインタラクティブにグラフ可視化する Chrome / Edge 拡張機能です。

## 特徴（Bookmarklet 版からの再設計ポイント）

- **あらゆる Redmine ページから即起動**:
  - **チケット詳細 (`/issues/123`)**: そのチケットを起点に 1 ホップの関連をグラフ表示
  - **一覧 / ガントチャート (`issues/gantt` 等)**: ページ内に表示されているチケット群を一括取得し、チケット間の関連リンク・外部関連チケットをグラフ表示
  - **その他ページ**: 前回閉じたグラフ状態を復元（または履歴サイドバー表示）
- **Manifest V3 準拠・完全オフライン対応**: `vis-network@9.1.9` を `vendor/` にローカル同梱（外部 CDN 不要）。
- **サーバー別 API キー設定**: Cookie 認証を受け付けない Redmine（401 エラーになる環境）向けに、設定画面（`⚙️ 設定`）から `Base URL` ごとに `X-Redmine-API-Key` を登録可能。
- **統合履歴 & 状態保存**: `chrome.storage.local` に複数サーバー横断の閲覧履歴（最大 200 件）と前回のグラフ配置を自動保存。

## 導入手順（開発者モードで読み込み）

1. Chrome / Edge で `chrome://extensions/` を開く
2. 右上の **「デベロッパー モード」** を ON にする
3. **「パッケージ化されていない拡張機能を読み込む」** から本フォルダ（`ChromeExt/rmnav`）を選択
4. Redmine ページを開いた状態で拡張アイコンをクリック（または `Alt+Shift+R`）
