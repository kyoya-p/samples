# ChromeDoodle 🎨

Webページ上に直接フリーハンド・図形・テキストを描画・注釈し、暗転クロップ領域のクリップボードコピーや画像貼り付けができる Manifest V3 対応の Chrome 拡張機能です。

---

## 🌟 主な機能

1. **フリーハンド描画 (Pen) & 十字カーソル精密スポイト機能 (Eyedropper)**
   - ページ上のどこでも滑らかなベジェ曲線で手書きメモやマーキングが可能。
   - **わかりやすいピペットアイコン**: ツールバーおよびパレットに見やすいスポイトアイコンを常時配置。
   - **十字カーソル（クロスヘア）ターゲット**: スポイト選択中（`I` キーまたはアイコン）はカーソルが十字になり、ピクセル単位の精密な狙い撃ちが可能。
   - **リアルタイム色プレビュー**: カーソル横に拡大ルーペと16進数カラーコード（例: `#3B82F6`）がリアルタイム表示され、クリックしたピクセルの色を描画色・図形色に即時反映。
   - 8色のクイックカラーパレット ＋ カスタムカラーピッカー対応。
   - 線の太さ（2px, 4px, 8px, 14px）を選択可能。

2. **Webページテキスト直接編集 (Edit Mode)**
   - ツールバーの編集アイコンまたは `W` キーを押すと、**閲覧中のWebページ上の文章や見出しを直接クリックしてタイピング書き換え可能**に（`document.designMode` 連携）。
   - リンクをクリックしても誤遷移せず、文字の修正・削除・追加がワープロ感覚で行えます。
   - 完了後は `Esc` キーまたは他のツール選択で復帰。テキストを書き換えた状態のまま、矢印や手書き注釈を入れたり、領域クロップして画像コピーできます。

3. **直線 & 矢印 (Line / Arrow) - 始点・終点ハンドラ対応**
   - 重要なポイントを指し示す直線および矢印の描画。自然で美しい鏃（やじり）形状。
   - **始点・終点ハンドラ**: 選択ツール（V）でクリックすると、始点と終点の2箇所に円形グリップが表示され、ドラッグすることで線の向き・長さ・角度を直感的に再調整可能（線本体をドラッグすると平行移動）。破線枠は表示されずクリーンです。

4. **矩形 & 楕円 (Rectangle / Ellipse) - 8方向リサイズ対応**
   - 枠線のみ・半透明ハイライト塗りつぶし・不透明塗りつぶしの3つの描画モードをワンクリックで切り替え。
   - **矩形 & 楕円の8点ハンドラ**: 選択時、四隅（比率維持）と上下左右の中点4点（縦横比変更）の計8点ハンドラが表示され、図形のサイズやアスペクト比を直感的に微調整可能です（Shiftキー併用で四隅も自由比率）。

5. **テキスト注釈 & 既存テキストの再編集 (Text / In-place Edit)**
   - ページ上の任意の場所をクリックしてテキストを入力。
   - **既存テキストの編集**: 配置済みのテキストをクリックして選択、またはダブルクリックすることで、その場でテキスト内容・文字色・フォントサイズ（18px〜48px）を再編集可能。

6. **暗転クロップエリア指定 (Darkened Crop Area)**
   - クロップツール選択時、切り抜きたい領域をドラッグで指定。
   - **枠外が半透明の暗色（`rgba(0, 0, 0, 0.62)`）でマスク**され、注目領域が一目でわかります。
   - 四隅・四辺の8箇所のハンドルで領域サイズ・位置を自由に微調整可能。
   - 領域サイズ（px）をリアルタイム表示。

6. **クリップボードへ領域コピー (Copy Crop Area to Clipboard)**
   - クロップ枠に付属する「📋 領域コピー」ボタンをクリックすると、Webページの背景スクリーンショットと描画注釈を合成し、指定枠の範囲のみを高解像度（Retina/DPR対応）PNG画像としてクリップボードへ直接コピー。
   - Slack, Discord, Google Docs, Notion, GitHub などへ `Ctrl+V` で即座に貼り付け可能。

7. **クリップボードを画像として重ねて置く & 8方向リサイズ (Paste Image & 8-point Resize)**
   - ツールバーの「貼付」ボタン、または描画モード中に `Ctrl+V`（Macは `Cmd+V`）を押すだけで、クリップボードにある画像をキャンバス上にオーバーレイ画像として配置。
   - **破線枠はつかずクリーンに表示**: 画像自体を邪魔する点線枠は一切表示されません。
   - **8方向リサイズ対応**:
     - **四隅の4点**: ドラッグすると、画像の**縦横比（アスペクト比）を保持したまま**拡大・縮小。
     - **上下左右の中点4点**: ドラッグすると、**縦横比を変更**して幅または高さのみを単独で自由に伸縮可能。
   - 配置された画像はドラッグで移動したり、その上からさらにペンやテキストで注釈可能。リサイズや移動もすべて Undo/Redo の対象です。

8. **完全な UnDo / ReDo スタック**
   - オブジェクト単位の履歴スタック管理により、手書きストローク、図形作成、テキスト入力、テキスト編集、画像貼り付け、移動、全消去のすべてを `Ctrl+Z` で元に戻し、`Ctrl+Y`（または `Ctrl+Shift+Z`）でやり直し可能。

9. **全画面コピー & PNG画像ダウンロード**
   - 画面全体の注釈付きキャプチャをクリップボードにコピー、またはPNGファイルとして保存。

10. **Shadow DOM による完全なスタイル隔離**
    - ホストWebページ側のCSS（Tailwind, Bootstrap, リセットCSS等）の影響を一切受けない Shadow DOM 構造を採用。どんなWebサイトでも美しいUIを維持します。

## 🚀 インストール手順 (Google Chrome)

1. Google Chrome を開き、アドレスバーに `chrome://extensions` と入力してEnterキーを押します。
2. 画面右上の **「デベロッパーモード」** をONにします。
3. 画面左上の **「パッケージ化されていない拡張機能を読み込む」** ボタンをクリックします。
4. 本フォルダ（`C:\Users\kyoya\projs\samples\2026\ChromeDoodle`）を選択します。
5. Chromeのツールバーに「ChromeDoodle」のアイコンが表示されます。

---

## 💡 使い方

1. 任意のWebページを開きます。
2. ツールバーの **ChromeDoodle アイコンをクリック** または ショートカット **`Alt + Shift + D`** を押すと、描画モードが起動します。
3. 画面上部にフロート表示されるツールバーからツールを選んで描画します。
   - ツールバー左端のつまみ（⠿）をドラッグして、画面上の好きな位置へ移動できます。
4. 描画モードを終了するには、ツールバー右端の「✕」ボタンを押すか、**`Esc` キー** を押します。
