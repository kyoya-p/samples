🕸️ Redmine Graph Navigator

Redmine のチケットの親子・関連を、別ウィンドウのグラフで可視化・探索するブックマークレット。

起動

  1. Redmine のチケット詳細ページ (/issues/123) でブックマークレットをクリック → そのチケットを起点にグラフ表示
  2. チケット詳細以外のページでクリック → 前回閉じた時と同じグラフを復元 (保存が無い場合は履歴サイドバーを表示)
  3. 既にナビウィンドウが開いている状態でチケット詳細以外からクリック → 画面は変えず前面に表示

初回はブラウザのポップアップブロック解除が必要な場合があります。

前回状態の復元

  • ノード、エッジ、ノード配置、拡大率/表示位置、関連フィルタ、レイアウト、選択中チケットを localStorage に自動保存 (ウィンドウを閉じた時・操作後)
  • 保存先は Redmine と同一オリジンのブラウザ内のみ。サーバー送信なし
  • チケット詳細ページから起動した場合は、その起点チケットで新規に描画 (前回状態は上書き)

上部のチェックボックスで関連ごとに表示/非表示を切替。「全選択」「全解除」で一括操作。

ノード操作

  • クリック: 右サイドバーに詳細表示 (「Redmineで開く」「関連展開」「除外」)
  • ダブルクリック: 関連を芋づる式に展開
  • ドラッグ: 位置調整
  • 金色の太枠: 起点チケット / 灰色: 完了系ステータス / トラッカー別に色分け

履歴

  • 起点として表示したチケットを自動記録。一覧クリックで別チケットを起点に再表示
  • 他サーバーの履歴にはサーバー名バッジを表示
  • 「🗑️ 履歴をクリア」: OK で全サーバー、キャンセルで現在のサーバーのみ削除

データ取得と注意

  • 通常は Redmine REST API (/issues/:id.json?include=relations,children)。API 無効環境では開いているチケットページの DOM から取得
  • Vis.js を CDN (cdnjs / unpkg) から読み込むため、CDN へ接続できる環境が必要
  • ブックマークレット本体は、このサイトの redmine-navi.js を読み込む小さなローダー。更新はサイト側の差し替えのみで全利用者に反映
  • Redmine の CSP (Content-Security-Policy) が外部スクリプトを禁止している場合は読み込みに失敗します
