# Bookmarklet集

Chrome内蔵のオンデバイスAI(`Proofreader` API / `Prompt API`=`LanguageModel`)を使った、
テキスト編集支援ブックマークレット。外部サーバーには送信せず、ブラウザ内で完結する。

## 前提条件

- Chrome (最新版、Gemini Nano対応バージョン)
- `chrome://flags` で以下を有効化しておくこと
  - `#optimization-guide-on-device-model`
  - `#writer-api-for-gemini-nano` などProofreader/Prompt APIに対応するフラグ
- 初回実行時にモデルのダウンロードが走る場合がある(以降はChromeにキャッシュされるため毎回はダウンロードされない)

## 導入方法

1. 各`.bm`ファイルの中身(`javascript:...`から始まる1行)をコピーする
2. ブックマークバーに新規ブックマークを作成し、URL欄に貼り付ける
3. 任意の名前をつけて保存する
4. 使いたいページでブックマークをクリックすると実行される

## AI-spellcheck.bm — スペルチェッカー

フォーカス中の入力欄/選択テキストの誤字脱字・文法ミスを自動検出して修正案を提示する。

**使い方**

1. スペルチェックしたい`textarea`/`input`/`contenteditable`にフォーカスするか、
   ページ上のテキストを選択する
2. ブックマークをクリックする
3. 右上にパネルが開き、自動でチェックが始まる
4. 修正後の全文と、検出された修正箇所の一覧が表示される
5. 「適用」を押すと元の入力欄/選択箇所が修正後のテキストに置き換わる
6. 誤りが無ければ「誤りは見つかりませんでした。」と表示される
7. パネルを閉じたい場合は「×」を押すか、ブックマークを再度クリックする(トグル動作)

内部的には`Proofreader` APIを優先して使用し、利用できない場合は`Prompt API`にフォールバックする。

## AI_editor.bm — AIエディタ

自由な指示文(プロンプト)を与えて、フォーカス中の入力欄/選択テキストを指示どおりに編集させる。
パネルには「ワーク領域」(編集対象のテキスト)と「指示」(編集指示)が別々の欄として表示される。

**使い方**

1. 編集したい`textarea`/`input`/`contenteditable`にフォーカスするか、
   ページ上のテキストを選択する(マークした内容が「ワーク領域」の初期値になる)
2. ブックマークをクリックする
3. 右上にパネルが開き、「ワーク領域」(編集対象、編集可)と「指示」の2つの欄が表示される
4. 「指示」欄に編集の指示を入力する(例: 「もっと丁寧な敬語にする」「要約する」「箇条書きにする」)
5. 「実行」を押すと、AIが「指示」に従って「ワーク領域」の内容を編集し、結果でワーク領域を更新する
6. 結果を見ながら指示を変えて再度「実行」すれば、ワーク領域をさらに編集し続けられる
   (ワーク領域は直接手で編集することもできる)
7. 「適用」を押すと、その時点の「ワーク領域」の内容で元のマーク箇所(入力欄/選択範囲)を置換する
8. パネルを閉じたい場合は「×」を押すか、ブックマークを再度クリックする(トグル動作)

内部的には`Prompt API`(`LanguageModel`)のみを使用する(自由指示に対応していない`Proofreader` APIは使わない)。

## 注意事項

- `contenteditable`要素への「適用」は`innerText`で書き換えるため、リッチテキストの書式(太字・リンクなど)は失われる
- AIの出力はそのまま`textContent`として描画しているため、生成結果にHTMLタグが含まれてもスクリプトとして実行されることはない
