# Bookmarklet集

Chrome内蔵のオンデバイスAI(`Proofreader` API / `Prompt API`=`LanguageModel`)を使った、
テキスト編集支援ブックマークレット。外部サーバーには送信せず、ブラウザ内で完結する。

## 前提条件

- Chrome (最新版、Gemini Nano対応バージョン)
- `chrome://flags` で以下を有効化しておくこと
  - `#optimization-guide-on-device-model`
  - `#writer-api-for-gemini-nano` などProofreader/Prompt APIに対応するフラグ
- 初回実行時にモデルのダウンロードが走る場合がある(以降はChromeにキャッシュされるため毎回はダウンロードされない)

## 導入方法

1. 各`.bm`ファイルの中身(`javascript:...`から始まる1行)をコピーする
2. ブックマークバーに新規ブックマークを作成し、URL欄に貼り付ける
3. 任意の名前をつけて保存する
4. 使いたいページでブックマークをクリックすると実行される

## AI-spellcheck.bm — スペルチェッカー

フォーカス中の入力欄/選択テキストの誤字脱字・文法ミスを自動検出して修正案を提示する。

**使い方**

1. スペルチェックしたい`textarea`/`input`/`contenteditable`にフォーカスするか、
   ページ上のテキストを選択する
2. ブックマークをクリックする
3. 右上にパネルが開き、自動でチェックが始まる
4. 修正後の全文と、検出された修正箇所の一覧が表示される
5. 「適用」を押すと元の入力欄/選択箇所が修正後のテキストに置き換わる
6. 誤りが無ければ「誤りは見つかりませんでした。」と表示される
7. パネルを閉じたい場合は「×」を押すか、ブックマークを再度クリックする(トグル動作)

内部的には`Proofreader` APIを優先して使用し、利用できない場合は`Prompt API`にフォールバックする。

## AI_editor.bm — AIエディタ

自由な指示文(プロンプト)を与えて、フォーカス中の入力欄/選択テキストを指示どおりに編集させる。
パネルには「ワーク領域」(編集対象のテキスト)と「指示」(編集指示)が別々の欄として表示される。

**使い方**

1. 編集したい`textarea`/`input`/`contenteditable`にフォーカスするか、
   ページ上のテキストを選択する(マークした内容が「ワーク領域」の初期値になる)
2. ブックマークをクリックする
3. 右上にパネルが開き、「ワーク領域」(編集対象、編集可)と「指示」の2つの欄が表示される
4. 「指示」欄に編集の指示を入力する(例: 「もっと丁寧な敬語にする」「要約する」「箇条書きにする」)
5. 「実行」を押すと、AIが「指示」に従って「ワーク領域」の内容を編集し、結果でワーク領域を更新する
6. 結果を見ながら指示を変えて再度「実行」すれば、ワーク領域をさらに編集し続けられる
   (ワーク領域は直接手で編集することもできる)
7. 「適用」を押すと、その時点の「ワーク領域」の内容で元のマーク箇所(入力欄/選択範囲)を置換する
8. パネルを閉じたい場合は「×」を押すか、ブックマークを再度クリックする(トグル動作)

内部的には`Prompt API`(`LanguageModel`)のみを使用する(自由指示に対応していない`Proofreader` APIは使わない)。

## redmine-navi — Redmine チケット関係図ナビゲーター

Redmine上で動作し、チケットの親子関係や関連（ブロック、先行・後続、関連、重複、コピー）を別ウィンドウでグラフィカルに可視化・探索するブックマークレット。
ネットワークグラフ描画には [Vis.js (vis-network)](https://visjs.github.io/vis-network/docs/network/) を使用し、インタラクティブにノードを探索・展開できる。

**主な機能**

- **別ウィンドウでのグラフィック表示**: `window.open` による専用ポップアップウィンドウで広々と関係図を俯瞰・操作
- **リレーション種別のチェックボックス絞り込み**:
  - ヘッダー直下のフィルターバーにあるチェックボックスで、表示する関連の種類をオン/オフ可能
  - `☑ 親子タスク` `☑ ブロック` `☑ 先行・後続` `☑ 関連` `☑ 重複` `☑ コピー`
  - 「全選択」「全解除」ボタンでワンタッチ切り替え
- **リレーションの色分け可視化**:
  - 🔴 **ブロック (blocks)**: 赤色の有向エッジ
  - 🔵 **先行・後続 (precedes / follows)**: 青色の有向エッジ
  - 🟢 **関連 (relates)**: 緑色の実線エッジ
  - 🟠 **重複 (duplicates)**: 橙色の有向エッジ
  - 🟣 **コピー (copied_to)**: 紫色の点線エッジ
  - ⚪ **親子タスク (subtask)**: 灰色の点線エッジ（親 → 子）
- **トラッカー・ステータス別のノード色分け**:
  - バグ/障害: 赤系
  - 機能/Feature: 青系
  - サポート: 黄/橙系
  - 完了・終了チケット: グレーアウト
  - 起点チケット: 金色の太枠強調
- **インタラクティブな探索**:
  - **ノードをクリック**: 右サイドバーにチケット詳細（題名、担当者、優先度、期日、進捗率、説明文等）を表示
  - **ノードをダブルクリック**: そのチケットの関連チケットをグラフ上に動的に展開
  - **「Redmineで開く」**: 選択したチケットのページを別タブで素早く開く
  - **「チケット追加」**: 任意のチケット番号を入力してグラフに追加・接続
  - **「除外」**: 不要なノードをグラフから除外
- **レイアウト切り替え**:
  - **自由配置 (力学モデル)**: 物理シミュレーションによる自然な配置（物理演算ON/OFF可能）
  - **ツリー(上下)**: 先行関係や親子関係を上から下に整列
  - **ツリー(左右)**: 先行関係や親子関係を左から右に整列
  - **全体フィット**: グラフ全体をワンクリックで画面中央にフィット
- **堅牢なデータ取得 (REST API & DOMフォールバック)**:
  - 通常は Redmine の REST API (`/issues/:id.json?include=relations,children`) 経由で取得
  - APIが無効な環境でも、現在開いているチケットページのDOMから親・子・関連を自動抽出して初期表示
- **閲覧履歴 (マルチサーバー対応)**:
  - 起点として表示したチケットを`localStorage`に最大200件まで自動保存（サーバー単位）
  - ヘッダーの「🕐 履歴」ボタンで左側に履歴サイドバーを開閉し、一覧からワンクリックで別チケットを起点に再表示
  - 複数のRedmineサーバー（最大10件）を横断して履歴を記録・表示し、他サーバーの履歴にはバッジを表示
  - 「🗑️ 履歴をクリア」で現在のサーバーのみ、または全サーバー分の履歴をまとめて削除可能
  - チケット詳細ページ以外（マイページ等）からブックマークレットを起動した場合は、前回閉じた時のグラフ（ノード・配置・表示位置・フィルタ等）を復元（保存が無ければ履歴サイドバーを表示）
- **ヘルプ**: ヘッダーの「❓ ヘルプ」で機能説明ページ(Web)を開く
- **配布方式**: ソースは `rmnav/` フォルダ（`redmine-navi.js` / `help.html` / `index.html` / `deploy.mjs` / `mise.toml`）。導入は http://c6303002l.win.sharp.co.jp/gantt-tool/rmnav/ のページからブックマークへ登録（ドラッグ&ドロップ）。ブックマークは同サイトの `redmine-navi.js` を読み込むローダー。本体更新は `rmnav/` で `mise run rmnav-deploy`（配布先 `\\c6303002l.win.sharp.co.jp\web\gantt-tool\rmnav\`）。旧版バックアップは `rmnav/redmine-navi-2609017.bm`

**使い方**

1. Redmine のチケット詳細ページ（`/issues/123` など）を開く
   （チケット詳細ページ以外で開いた場合は、前回のグラフを復元します）
2. ブックマークレットをクリックする
   （初回のみブラウザのポップアップブロック解除が必要な場合があります）
3. ポップアップウィンドウが開き、対象チケットを中心としたリレーショングラフが表示される
4. ノードをクリックして詳細を確認したり、ダブルクリックでさらに先の関連チケットを芋づる式に展開して依存関係を調査できる
5. ヘッダーの「🕐 履歴」から、これまでに表示したチケットへすぐに切り替えられる

## 注意事項

- パネル右上の帯(「×」がある部分)をドラッグするとパネルを自由に移動できる (AIツール系)
- `contenteditable`要素への「適用」は`innerText`で書き換えるため、リッチテキストの書式(太字・リンクなど)は失われる
- AIの出力はそのまま`textContent`として描画しているため、生成結果にHTMLタグが含まれてもスクリプトとして実行されることはない
- `redmine-navi` はCDNからVis.jsライブラリをロードします。インターネット接続環境、またはCDNへのアクセスが許可された環境でご利用ください。
