# mdedit 使い方メモ

`mdedit.html` をブラウザで開くだけ（1ファイル完結・インストール不要）。

# 起動

- 左が Markdown ソース、右がプレビュー。上部の `表示:` メニューから `ソース / 分割 / プレビュー` を選んで切替（現在のモードがボタンに表示され、メニュー内では `✓` が付く）。分割時、画面幅が820px未満だと自動的に縦→横並びに切り替わる（手動トグルではない）
- 本文は入力が止まった 0.3 秒後に URL の `#md=` へ自動反映（URLエンコードのみ・圧縮やbase64ではない）。`URL をコピー` で本文入りURLが共有できる
- パラメータ無しで開くと前回の内容をこの端末から復元
- `.md` ファイルをウィンドウにドロップすると、そのファイルをソースとして読み込む



# プレビュー（直接編集）モード

`直接編集` を ON にしたときの操作説明。マークダウン作法に則る。

## 基本操作

- [ ] Ctrl-X/C/V : カット/コピー/ペースト（ブラウザ標準）

- [ ] Ctrl-Z/Y : Undo / Redo（ブラウザ標準）

## 書式

- [ ] `Ctrl+B` 太字 / `Ctrl+I` 斜体 / `Ctrl+K` リンク / `Ctrl+E` コード / `Ctrl+1〜6` 見出し / `Ctrl+S` 保存
- [ ] リストや引用の途中で `Enter` すると次の項目を自動で継続（空項目で `Enter` すると抜ける）

## 表の操作

- [ ] ツールバーの `表` … 行数・列数を聞いてから挿入

- [ ] `Tab` / `Shift+Tab` … 次 / 前のセルへ
- [ ] 最終セルの末尾で `Tab` または `→` … 表の右へ抜ける。そこで `Tab` を押すと行追加、`Enter` で表の下に段落を作成
- [ ] セル内で `Enter` … セル内改行。`Shift+Enter` … 表を抜けて下に段落
- [ ] セル内で `CTRL-V` 
  - [ ] コピー元がセルの場合、セル内容を現在キャレットがあるセルにコピー。
  - [ ] コピー元が複数セルの場合、現在キャレットがあるセルを左上端セルとして複数セルにまたがりコピー
- [ ] **セルを右クリック** … 行/列の 挿入・削除 メニュー（ヘッダー行の削除や最後の1列の削除など、できない操作は自動でグレーアウト）
  - [ ] 選択中に**右クリック**すると、選択した行/列をまとめて挿入・削除。`Delete` キーでも行/列ごと削除できる
  - [ ] **移動はドラッグ**: 
  - [ ] 行列選択中
    - [ ] CTRL-X/C/Vは行列のカット/コピー/ペースト
    - [ ] ハンドラをつかんで動かすと、他の行/列がその場でアニメーションしながら道を空け、離した位置へ移動（複数選択していればまとめて移動）
- [ ] セル選択（行/列選択とは別・スプレッドシート風）
  - [ ] `Ctrl+クリック` … そのセルだけを選択
  - [ ] `Ctrl+ドラッグ`（未選択のセルから開始）… 矩形範囲で複数セルを選択
  - [ ] 他の場所をクリックすると選択解除
  - [ ] セル選択中
    - [ ] テキストのキャレットは標示されない
    - [ ] `Delete` … 選択したセルの**内容**をクリア（行/列自体は削除されない）
    - [ ] CTRL-X/C/Vはセルのカット/コピー/ペースト
    - [ ] ドラッグで移動。CTRL+ドラッグでコピー。移動コピー先のセル内容は失われる
