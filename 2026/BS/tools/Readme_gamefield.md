# Battle Spirits CLI Simulator & Neural Network Evaluator (gamefield)

バトルスピリッツのスタンダードルールに基づき、任意のデッキにおいて各局面で選択肢に評価を行うLMニューラルネット（強化学習）基盤および対話型CLIシミュレータ。

## 1. 実行方法

プロジェクトの `tools` ディレクトリにて、`amper` を使用して実行。

```powershell
# 対話型シミュレータ起動 (デフォルト: deck-fara.yaml vs deck-kogyo.yaml)
.\amper.bat run -m gamefield

# 任意のデッキを指定して対戦シミュレーション
.\amper.bat run -m gamefield -- -d1 deck-fara.yaml -d2 deck-kogyo.yaml

# 強化学習 (Self-Play 自己対戦によるポリシー最適化・重み更新)
.\amper.bat run -m gamefield -- --train --epochs 10
```

## 2. 主な機能とアーキテクチャ

- **スタンダードルール完全準拠**:
  - 初期配置（ライフ5、リザーブ4・うちソウルコア1、手札4枚、デッキ）。
  - 先攻1ターン目制限（コアステップスキップ、契約編最新ルールに基づくドローステップ対応）。
  - 各ステップ自動進行（スタート → コア → ドロー → リフレッシュ）。
  - コスト計算とシンボル軽減（フィールドシンボルによる動的軽減）。
  - コア移動とスピリット消滅処理（Lv1維持コスト不足による自動トラッシュ移動）。
  - 同一盤面ループの検出と禁止手（`isForbidden`）判定。

- **任意のデッキ対応**:
  - YAML形式（`cards: { <CardID>: <Count> }`）およびMarkdown形式のデッキレシピを自動読み込み。
  - ローカルキャッシュ（`~/.bscards/yaml/$cardNo.yaml`）からコスト、属性色、軽減、Lvコスト、系統、シンボル数を動的取得。
  - 未知カードへの安全なフォールバック（Placeholder）。

- **LMニューラルネット（強化学習・盤面評価器）**:
  - **特徴量エンコーダ (`FeatureEncoder`)**: 盤面状態を520次元ベクトルにエンコード（ステップOne-Hot、ターン数正規化、ライフ/コア/手札、フィールドオブジェクト各25次元［存在・カテゴリ・コア/ソウル・疲労・Lv・コスト・色・シンボル・系統］）。
  - **多層パーセプトロン (`NeuralBoardEvaluator`)**: Input(520) → Dense(256, ReLU) → Dense(256, ReLU) → Output(1, Tanh) による価値関数 $V(s) \in [-1.0, 1.0]$ 予測。
  - **強化学習 (`SelfPlayTrainer`)**: 自己対戦（Self-Play）による経験データ収集、優先度付き中間報酬（相手ライフ削り > 相手スピリット除去 > 自軍展開 > ソウルコア温存 > 勝敗結果）、Adam最適化器によるオンライン勾配更新。
  - **局面選択肢評価**: 各合法手適用後の次局面を予測・評価し、ネガマックス視点で各選択肢にリアルタイム評価値（`[AI評価値: +0.XXX]`）を付与。

## 3. 操作コマンド

対話型シミュレータでの入力：
- **[番号]**: リストに表示されたアクション（召喚/配置、コア移動、アタック、ブロック等）を実行。
- **Enter または a**: AI自動決定（評価値が最も高い推奨アクションを自動実行）。
- **n**: ステップ終了 / パス。
- **q**: サレンダー（投了終了）。
