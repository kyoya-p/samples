Nano Translate 設定

翻訳先言語

ポップアップ・右クリック・ショートカット・ページ内翻訳の翻訳先。既定はブラウザの言語設定 (UI 言語 → 受け入れ言語の順で、対応する最初の言語。どれも非対応なら English)。ポップアップで翻訳先を変えると、ここの設定も変わる。

ページ翻訳

ハイライト: 翻訳モード中、まだ訳していない・訳せなかったテキストに薄い黄色、コードと判定して翻訳しない部分に薄い青の背景 (ページの DOM は変えない)。原文表示に戻すと消える。既定は 未翻訳 ON・コード OFF。

デバッグ: 翻訳モード中、テキストにマウスを合わせると、その翻訳ブロックの詳細をダイアログ表示。翻訳単位 (ブロック / テキストノード)、状態 (翻訳済み・辞書から / AI の所要時間・処理待ち・失敗・テキストノード単位への切替とその理由)、AI への入力 (目印付きテキスト) と出力、目印と要素の対応、コード判定の根拠とパラメータ (その場で編集・再判定)。あわせて、AI で翻訳中の部分を薄い緑でハイライトし、入力と生成中の出力を右下のパネルにリアルタイム表示 (ストリーミング)。既定は OFF。

複数の翻訳単位 (ブロック・テキストノード) を JSON 文字列配列にまとめ、原文の合計がこの文字数までなら 1 回で AI 翻訳する (表示中の部分が先、続けて画面外の近い部分)。応答の個数が合わない・目印が崩れた単位は 1 つずつ翻訳し直す。この文字数を超えるブロックはテキストノード単位に分割。既定 2000。小さくすると安定、大きくすると AI の呼び出し回数が減る。次回のページ翻訳から反映。

ソースコードを翻訳対象から外す。判定は (1) pre / code / kbd / samp と主要なシンタックスハイライタ (highlight.js・Prism・CodeMirror・Monaco 等) のタグ・クラス、(2) 文脈からの推定 (等幅フォント・記号の密度・予約語・行末の ; {}・インデント。句点が複数ある文章はコードとみなさない)。推定は完全ではない。既定は ON。次回のページ翻訳から反映。

コード判定のパラメータ

pre / code タグや、シンタックスハイライタのクラスが付いた要素は、常にコードと判定する。それ以外の要素は、テキスト (先頭 2000 文字) を下の条件で採点し、満たした条件の点の合計がしきい値以上ならコードと判定して、翻訳しない。

  • 点を上げる / しきい値を下げる → コードと判定しやすくなる (翻訳しない部分が増える)
  • 点を 0 にする → その条件を使わない。点を負にする → 満たすと減点
  • 空欄・不正値は既定値。変更は次回のページ翻訳から反映

辞書 (翻訳キャッシュ)

翻訳済みの原文と訳文を端末内 (chrome.storage.local) に保存。同じ原文・翻訳先なら再翻訳せずに辞書の訳文を使う。訳文を編集すると以後の翻訳に反映される。

保存上限を超えると参照日時の古い順に削除 (50 件保存するごとに確認)。最大文字数を超える原文は辞書に保存しない。空欄・不正値は既定値。
