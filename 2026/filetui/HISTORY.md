# filetui 作業ログ (Work Log)

## 2026-09-17 〜 2026-09-29

### 1. 左右2ペイン構造 & インラインツリー展開
- `state.panes = [leftPane, rightPane]` によるデュアルペインアーキテクチャの導入。
- `Tab` キーで左右アクティブペインを瞬時に切り替え可能に実装。
- ディレクトリ行での `→` / `l` によるインラインツリー展開（`▼`、`├─`, `└─`, `│` 罫線付き）および `←` / `h` による折りたたみ（`▶`）を実装。
- ツリー展開時の階層深さ (`depth`)、親パス追跡、および子要素キャッシュ (`childrenCache`) を導入。

### 2. マウス操作・ドラッグ＆ドロップ機能
- SGR拡張マウス報告 (`CSI ?1000h`, `?1002h`, `?1006h`) を活用したマウスイベント解析。
- 左クリックによるカーソル移動、ダブルクリックによるディレクトリ侵入 / ファイル起動。
- マウスドラッグ＆ドロップによるペイン間（左→右、右→左）のファイル/ディレクトリ転送（コピー / 移動の選択プロンプト）。
- リモートペインとのドラッグ＆ドロップ時は自動 SCP アップロード/ダウンロードを実行。
- エクスプローラ等からの外部ファイルドロップ検出 (`parseDropPayload`) と自動転送。

### 3. パス直接編集・ナビゲーション強化
- 最上段パスバー行 (y=1) の左クリック、または `C` キーによって直接パス編集プロンプトを起動。
- カレントパスを事前に入力欄へ展開し、カーソル左右移動 (`←`/`→`/`Home`/`End`)、文字挿入、`Backspace`/`Delete` によるインライン編集に対応。
- 入力値から以下の形式を自動判別:
  - ローカル Windows ドライブパス (`C:\...`, `D:/...`)
  - UNC パス (`\\server\share`, `//server/share`)
  - ローカル POSIX パス (`/var/log`, `~/...`, `./...`)
  - SSH リモートパス (`ssh://[user@]host[:port]/path`, `[user@]host:path`, ホストエイリアス単体 `ub2311`)
- 空入力時は即座にローカルディレクトリへ復帰。

### 4. セッション永続化 (前回状態の自動復元)
- 終了時や移動時に左右ペインのパス・SSH接続先・アクティブペインを `~/.filetui-state.json` に保存 (`saveSessionState`)。
- 引数なしで起動された場合に前回の左右ペイン状態を自動復元 (`loadSessionState`)。

### 5. UI・レイアウトの最適化
- 左右ペイン上部の `[左]` / `[右]` の明示ラベルを廃止し、アクティブペイン側のパスバー全体を反転ハイライト表示することでシンプルかつ直感的な見た目へ刷新。
- ファイルサイズおよび日付表示のカラム幅・フォーマットを見直し、ファイルサイズが見切れないようレイアウト調整。
