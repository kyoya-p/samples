# filetui

ターミナル上で動作する **左右2ペイン・ツリー形式ファイルマネージャ** (TUIアプリ)。**PowerShell** や Windows Terminal で軽快に動作し、
**SSH によるリモート Linux のファイル管理** にも対応。**マウス操作によるペイン間ドラッグ＆ドロップ** や、Windows 環境での **エクスプローラからの外部ファイル D&D** (リモートへの自動 SCP アップロード含む) もサポート。
依存パッケージゼロ、Node.js 標準 API および OS 標準の OpenSSH (`ssh`, `scp`) のみで動作します。

- 実装: Node.js (ESM、`filetui.mjs` 単一ファイル)
- 動作要件: Node.js >= 20、VTシーケンス対応端末 (Windows Terminal / PowerShell 7 / WSL / macOS / Linux)
- 確認環境: Node.js v24.20.0 / Windows 11 (OpenSSH for Windows 9.5p1)

## 実行

```shell
# --- 起動 (引数なしの場合は前回の左右ペイン・接続状態を自動復元) ---
node filetui.mjs

# --- 左右ペインのパスを指定して起動 ---
node filetui.mjs C:/Users D:/work
node filetui.mjs \\\\server\\share /var/log   # UNCパス / POSIXパス対応
node filetui.mjs . ssh://ub2311/var/log       # 左: ローカル / 右: リモート Linux

# --- SSH リモート Linux 管理 ---
node filetui.mjs ssh://ub2311                  # ~/.ssh/config のホスト指定 (リモートHOME)
node filetui.mjs ssh://ub2311/var/log          # ~/.ssh/config のホスト指定 (リモートHOME)
node filetui.mjs ssh://user:password@host:22/tmp

node filetui.mjs --help
```

mise 利用時:

```shell
mise run tui                      # 起動
mise run test                     # ヘッドレステスト
```

## 画面

```
 C:\Users\sharp\dev                 │ [SSH: ub2311] /var/log
 8/10件 | sort:name↑              │ 12/14件 | Tab:切替 C:SSH ?:ヘルプ
 ▼ src/                    <DIR>  │   nginx/                 <DIR>
   ├─ filetui.mjs          65.4K  │   syslog                 1.2M
   └─ test.mjs             24.0K  │   auth.log               45.0K
   Readme.md                8.5K  │ ...
--------------------------------------------------------------------------------
 C:\Users\sharp\dev | ドラッグ中 1件 — ドロップ先ペインまたはディレクトリで離すと転送
```

- **左右2ペイン**: `Tab` キーでアクティブペインを左右に切り替え。現在操作中のペインが反転ヘッダで強調表示されます。
- **インラインツリー表示**: ディレクトリ行で `→` または `l` を押すとその場でツリー展開 (`▼`)、`←` または `h` で折りたたみ (`▶`)。
- **マウスドラッグ＆ドロップ**: 左ペインのファイル/フォルダをマウスで掴んで右ペイン（またはその中の特定フォルダ）へドラッグして離すと、コピーまたは移動 (`c`/`m`/`Esc`) が即座に行えます。リモートペインへドロップした場合は **自動 SCP アップロード/ダウンロード** が走ります。

ディレクトリは青、シンボリックリンクは水色、アーカイブは紫、実行可能系は緑。選択行の先頭に `*`。
日本語などの全角文字は表示幅2として桁揃え。

## SSH / リモート Linux 機能

OpenSSH (`~/.ssh/config` の設定、秘密鍵、ssh-agent、ProxyJump 等) をそのまま利用して透過的にリモート Linux を管理できます。

- **起動時指定**: `node filetui.mjs [user@]host[:パス]`
- **アプリ内切り替え (`C` キー)**:
  - いつでも `C` キーを押して `SSH接続先 (例: user@host:/path, 空でローカル):` を入力可能
  - 空入力で即座に元のローカルディレクトリへ復帰
- **ローカル ↔ リモート間のシームレス転送**:
  - ローカルで `c` (コピー) または `x` (切り取り) → `C` でリモートへ切り替え → `p` (貼り付け) で **自動 SCP アップロード**
  - リモートで `c` または `x` → `C` で空入力 (ローカル復帰) → `p` で **自動 SCP ダウンロード**
- **リモートファイル操作**:
  - ディレクトリ作成 (`n`)、ファイル作成 (`N`)、リネーム (`r`)、削除 (`d` / 確認付き `rm -rf`)
  - 内蔵テキストビューア (`v`)、Windows 既定アプリで開く (`o` / 一時DLして起動)
  - リモートフルパスのクリップボードコピー (`y` / `user@host:/path` 形式)
- **パスワード・ホスト鍵の対話入力対応**:
  - 初回接続時やパスワードが必要な場合、自動的に対話画面へ切り替えて認証完了後に TUI を復帰

## マウス操作

SGR拡張マウス報告 (`CSI ?1000h` / `?1002h` / `?1006h`) を使用。

| 操作 | 動作 |
| --- | --- |
| 左クリック (一覧行) | カーソル移動 |
| 左クリック (最上段パスバー) | **パス編集プロンプト起動** (直接入力・編集してジャンプ) |
| 左ダブルクリック | ディレクトリへ入る / ファイルを開く (リモート時はビューア) |
| 右クリック | 選択トグル |
| 中クリック | 親ディレクトリ |
| ホイール | スクロール (一覧・ビューア・ヘルプ) |
| 左ドラッグ → ディレクトリ行で離す | そのディレクトリへ **コピー / 移動** (`c` / `m` で選択、`Esc` 中止) |
| `M` キー | マウス捕捉 ON/OFF — OFF 時は端末側のテキスト範囲選択が可能 |

ドラッグ対象は **選択があれば選択全件、無ければドラッグ開始行**。ドロップ先がファイルの場合は
転送せず警告。ディレクトリを自身の配下へドロップする操作は拒否。

## ファイルの D&D (Windows)

エクスプローラからターミナルウィンドウへファイルをドロップすると、Windows Terminal / conhost が
**パス文字列を stdin へ送出**する。filetui はこれを検出し、通常のキー入力と区別して
「現ディレクトリへコピー / 移動」の選択に変換する。

```
 外部から 2件  ->  /var/log    c:コピー  m:移動  Esc:中止
```

- **リモート表示中の D&D**: エクスプローラからドロップされたファイルを **リモート Linux 宛てに SCP 自動アップロード**！
- 複数ファイルの同時ドロップ可 (引用符付き / 裸のパス、混在可)
- 判定条件: `C:\...` / `\\server\...` / `/...` 形式で、トークン全てがパスであること。
  通常のキー入力や入力プロンプト表示中は誤爆しない
- 実在しないパスはエラー表示のみで無操作

## キー操作
 
| キー | 動作 |
| --- | --- |
| `Tab` | **左右ペイン切替** (左 ↔ 右のアクティブ切り替え) |
| `C` | **パス編集 / SSH接続先切替** (カレントパスが入力欄に入り、左右移動・削除・編集してEnterで移動。UNC `\\server\share`, `/パス`, `user@host:/path`, 空でローカル復帰) |
| `↑`/`k` `↓`/`j` | カーソル移動 |
| `PgUp` `PgDn` | ページ移動 |
| `Home`/`g` `End`/`G` | 先頭 / 末尾 |
| `→` / `l` | **ツリー展開** (ディレクトリを開いて子要素を表示) |
| `←` / `h` | **ツリー折りたたみ** (子要素を閉じる / 親要素へジャンプ) |
| `Enter` | ディレクトリへ入る (ルート変更。ファイルはビューア / 既定アプリで開く) |
| `Backspace` | 親ディレクトリへ (ルート変更) |
| `~` | ホームディレクトリ (リモート時はリモートの `$HOME`) |
| `Space` | 選択トグル |
| `a` | 全選択 / 全解除 |
| `.` | 隠しファイル表示トグル |
| `/` | 名前フィルタ (空入力で解除) |
| `s` / `S` | ソート基準 (name→size→mtime→ext) / 昇降切替 |
| `R` | 両ペインの再読み込み |
| `c` / `x` | コピー元 / 移動元として登録 (他ペインへ `p` で貼り付け可能) |
| `p` | 現ペインへ貼り付け (ホスト間跨ぎは SCP 転送) |
| `d` / `Delete` | 削除 (確認あり) |
| `r` | リネーム |
| `n` / `N` | ディレクトリ作成 / 空ファイル作成 |
| `v` | テキストビューア (バイナリ検出・4MB上限) |
| `o` | 既定アプリで開く (リモート時は一時取得して開く) |
| `y` | フルパスをOSクリップボードへ |
| `M` | マウス捕捉 ON/OFF |
| `?` | ヘルプ (`j`/`k` でスクロール) |
| `q` / `Ctrl-C` | 終了 (入力中は `Esc` でキャンセル) |

操作対象は **選択があれば選択全件、無ければカーソル位置**。

## 安全側の仕様

- 削除は必ず `y/N` 確認。既定は中止
- D&D・貼り付けとも同名衝突は上書きせず `名前 (2).拡張子` へ自動リネーム
- ディレクトリを自身の配下へ転送する操作は拒否
- ドライブ跨ぎの移動は `rename` 失敗 (EXDEV) 時にコピー＋削除へフォールバック
- 1件ごとに成否を集計し、失敗があれば件数と最初のエラーをステータス行に表示
- ビューアはバイナリ (NULバイト検出) と 4MB 超を拒否
- 終了時 (`q` / `Ctrl-C` / SIGTERM / 例外) にマウス捕捉・代替画面・カーソルを必ず復元
