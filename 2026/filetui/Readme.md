# filetui

ターミナル上で動作するファイルマネージャ **TUIアプリ**。**マウス対応**、Windows環境では
**エクスプローラからのファイル D&D** にも対応。依存パッケージゼロ、Node.js 標準APIのみ。

- 実装: Node.js (ESM、`filetui.mjs` 単一ファイル)
- 動作要件: Node.js >= 20、VTシーケンス対応端末 (Windows Terminal / PowerShell 7 / WSL / macOS / Linux)
- 確認環境: Node.js v24.20.0 / Windows 11

## 実行

```shell
node filetui.mjs             # カレントディレクトリ
node filetui.mjs C:/Users    # 起動ディレクトリ指定
node filetui.mjs --help
```

mise 利用時:

```shell
mise run tui                 # 起動
mise run test                # ヘッドレステスト
```

## マウス操作

SGR拡張マウス報告 (`CSI ?1000h` / `?1002h` / `?1006h`) を使用。

| 操作 | 動作 |
| --- | --- |
| 左クリック | カーソル移動 |
| 左ダブルクリック | ディレクトリへ入る / ファイルを既定アプリで開く |
| 右クリック | 選択トグル |
| 中クリック | 親ディレクトリ |
| ホイール | スクロール (一覧・ビューア・ヘルプ) |
| 左ドラッグ → ディレクトリ行で離す | そのディレクトリへ **コピー / 移動** (`c` / `m` で選択、`Esc` 中止) |
| `M` キー | マウス捕捉 ON/OFF — OFF 時は端末側のテキスト範囲選択が可能 |

ドラッグ対象は **選択があれば選択全件、無ければドラッグ開始行**。ドロップ先がファイルの場合は
転送せず警告。ディレクトリを自身の配下へドロップする操作は拒否。

## ファイルの D&D (Windows)

エクスプローラからターミナルウィンドウへファイルをドロップすると、Windows Terminal / conhost が
**パス文字列を stdin へ送出**する。filetui はこれを検出し、通常のキー入力と区別して
「現ディレクトリへコピー / 移動」の選択に変換する。

```
 外部から 2件  ->  C:\work\dest    c:コピー  m:移動  Esc:中止
```

- 複数ファイルの同時ドロップ可 (引用符付き / 裸のパス、混在可)
- 判定条件: `C:\...` / `\\server\...` / `/...` 形式で、トークン全てがパスであること。
  通常のキー入力や入力プロンプト表示中は誤爆しない
- 実在しないパスはエラー表示のみで無操作
- macOS / Linux でも端末がパスを送出する設定なら同様に動作 (Windows Terminal で確認)

## キー操作

| キー | 動作 |
| --- | --- |
| `↑`/`k` `↓`/`j` | カーソル移動 |
| `PgUp` `PgDn` | ページ移動 |
| `Home`/`g` `End`/`G` | 先頭 / 末尾 |
| `Enter`/`→`/`l` | ディレクトリへ入る (ファイルは既定アプリで開く) |
| `←`/`h`/`Backspace` | 親ディレクトリ (元の位置にカーソル復元) |
| `~` | ホームディレクトリ |
| `Space` | 選択トグル |
| `a` | 全選択 / 全解除 |
| `.` | 隠しファイル表示トグル |
| `/` | 名前フィルタ (空入力で解除) |
| `s` / `S` | ソート基準 (name→size→mtime→ext) / 昇降切替 |
| `R` | 再読み込み |
| `c` / `x` | コピー元 / 移動元として登録 |
| `p` | 現ディレクトリへ貼り付け |
| `d` / `Delete` | 削除 (確認あり) |
| `r` | リネーム |
| `n` / `N` | ディレクトリ作成 / 空ファイル作成 |
| `v` | テキストビューア |
| `o` | 既定アプリで開く |
| `y` | フルパスをOSクリップボードへ |
| `M` | マウス捕捉 ON/OFF |
| `?` | ヘルプ (`j`/`k` でスクロール) |
| `q` / `Ctrl-C` | 終了 (入力中は `Esc` でキャンセル) |

操作対象は **選択があれば選択全件、無ければカーソル位置**。

## 安全側の仕様

- 削除は必ず `y/N` 確認。既定は中止
- D&D・貼り付けとも同名衝突は上書きせず `名前 (2).拡張子` へ自動リネーム
- ディレクトリを自身の配下へ転送する操作は拒否
- ドライブ跨ぎの移動は `rename` 失敗 (EXDEV) 時にコピー＋削除へフォールバック
- 1件ごとに成否を集計し、失敗があれば件数と最初のエラーをステータス行に表示
- ビューアはバイナリ (NULバイト検出) と 4MB 超を拒否
- 終了時 (`q` / `Ctrl-C` / SIGTERM / 例外) にマウス捕捉・代替画面・カーソルを必ず復元

## テスト

```shell
node test.mjs      # 104 項目
```

TTY無しで内部状態を直接駆動するヘッドレステスト。一時ディレクトリを作成し、
一覧/移動/フィルタ/ソート/作成/リネーム/コピー/移動/衝突リネーム/削除/ビューア/描画幅、
およびマウス (クリック・ダブルクリック・右/中クリック・ホイール・行座標変換)、
アプリ内D&D、外部ドロップ文字列の解析と転送を検証。

対話実行時の描画確認は端末が必要なため、本テストの対象外。

## 構成

| ファイル | 内容 |
| --- | --- |
| `filetui.mjs` | 本体。表示幅計算 → 状態 → 読み込み → 描画 → ファイル操作 → マウス/D&D → キー処理 → 起動 |
| `test.mjs` | ヘッドレステスト |
| `mise.toml` | `tui` / `test` タスク |

`filetui.mjs` は直接実行時のみ起動し、`import` 時は内部関数を公開 (テスト用)。
